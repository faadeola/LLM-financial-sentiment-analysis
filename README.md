# LLM-financial-sentiment-analysis
Using a labelled dataset of 5842 words, which is a combination of formal sentences drawn from financial news with short, informal sentences resembling stock market social media posts [(`Kaggle`)](https://www.kaggle.com/datasets/sbhatti/financial-sentiment-analysis), and given one of three sentiment labels (`positive`, `negative`, or `neutral`). This study evaluates two methods for financial sentiment classification. The first method uses `logistic regression and TF-IDF features` to create a traditional baseline. The second is `FinBERT`, a `BERT-based language model` that was refined using `Low-Rank Adaptation (LoRA)` after being pretrained on financial information. Both methods are evaluated with and without hyperparameter adjustment, resulting in a total of four models.
